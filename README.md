# ShoeForm releases

Tested releases of ShoeForm, cork pieces for shoe lasts. Installed ShoeForm updates itself from here when
it starts.

## Install (once per computer)

**Windows:** open PowerShell and paste:

```
powershell -ExecutionPolicy ByPass -c "irm https://github.com/featheredape/shoeform-releases/releases/latest/download/install.ps1 | iex"
```

**Linux or Mac:** open Terminal and paste:

```bash
curl -LsSf https://github.com/featheredape/shoeform-releases/releases/latest/download/install.sh | sh
```

Then start ShoeForm from its icon on the Desktop. Pasting the line again repairs an installation.
